### AWS Security Fundamentals Second Edition

#### Learning Objectives
  - identify security benefits and responsibilities when using aws cloud
  - describe the access control and management features of aws
  - identify the different data protection services to secure sensitive data
  - describe how network access to you aws resources can be secured
  - determine the aws services uses foro security logging and monitoring
    
#### Design principles
  - implement strong identity foundation
  - enable traceability
  - apply security at all layers
  - automate security best practices
  - protect data in transit and at rest
  - enforce the priciple of least previlege
  - prepare for security events

## *2. design principles of the aws cloud*
- well-architected framework
    - how to use waf to:
      -   desing and build resilient, highly available and cost optimized environments
- what is waf? 
- design principles:
  - stop guessing capacity
  - test systems at production scale
  - automate architecture
  - allow for evelutionary changes
  - improve through game days
  - run test
 ---
- 6 pillars: 
  - operational excellence
    - ability to support development, run workloads effectively, gain insight into their operations, and to continiously improve supporting processes and procedures to deliver business value.
    - 5 design principles
      - perform operations as code
      - make frequent, small, reversible changes
      - refine operations procedures frequenctly
      - anticipate failures
      - learn from all operational failures
  - security
    - ability to protect date, system and assets to take advatages of cloud technology to improve security
    - 7 design principles
      -  implement strong identity foundation
      -  maintain traceability
      -  apply security at all layers
      -  automate security best practices
      -  protect data in transit and at rest
      -  keep people away from data
      -  preparte for security events
  - reliability
    - ability of a workload to perform its intended function correctly and consistenntly when it's expected to
    - ability to operate and test the workload through its total lifecycle
    - 5 design principles
      - automatically recover from failure
      - test recovery procedures
      - scale horizontally to incrase aggregate workload availability
      - stop guessing capacity
      - manage change in automation
  - performance efficiency
    - ability to use computing resouces efficiently to meet system requirements and to maintain that efficiency as demand changes and technologies evolve
    - 5 design principles
      - democratize advances technologies
      - go global in minutes
      - user serverless architectures
      - experiment more often
      - consider mechanical synpathy
  - cost optimization
    - ability to run systems to deliver busines value at the lowest price point
  - sustainability
    - environmental impact, energy consumpthing and efficiency to reduce resource usage
    - 6 design principles
      - understand your impact
      - establish sustainability goals
      - maximize utilization
      - anticipate and adopt new, more efficient hardward and software offerings
      - use manage services
      - reduce the downtream impact of your cloud workloads

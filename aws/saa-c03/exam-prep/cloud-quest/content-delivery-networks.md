### Content Delivery Networks

- CDN
- Amazon CloudFront provides a global network of edge locations

- an edge location is where end users access aws services from points closer to them geographically
- these locations can serve as a cache for frequently accessed data providing latency reduction
- is a web service that speeds up distribution of static or dynamic web content by caching content at aws edge locations
- fast content delivery
- cost-effective
- integration with aws
- aws has over 400 edge locations around the globe
- 550+ points of present

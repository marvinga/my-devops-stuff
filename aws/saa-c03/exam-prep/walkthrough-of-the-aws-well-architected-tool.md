### Walkthrough of the AWS Well-Architected Tool	

- Lab overview
- *As a solutions architect, you use AWS Well-Architected Tool to document your architecture decisions, provide recommendations for improving your workload based on best practices, and guide you in making your workloads more reliable, secure, efficient, and cost-effective.*

- Objectives
  - Create a workload using AWS Well-Architected Tool.
  - Perform a review.
  - Save a milestone.
  - View an AWS Well-Architected Tool milestone report.
